## 🚀 How to Run & View the Website

The website is engineered with zero external build dependencies:

1. **Directly in your Browser**:
   - Simply double-click [`index.html`](file:///c:/Vismaya%20Pradeep-Portfolio/index.html) to open it in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.

2. **Via Local HTTP Server** (Optional):
   - If you have Python installed: `python -m http.server 8000`
   - If you have Node.js installed: `npx serve .`
   - Using VS Code / IDE: Right-click `index.html` and select **Open with Live Server**.

## 📄 Generating PDF Resume

1. Click the **"Resume"** button in the navigation bar or the **"Download / Print Resume"** card in the Contact section.
2. Click **"Print / Save PDF"** inside the modal (or press `Ctrl + P`).
3. Set your destination to **"Save as PDF"**. The CSS print stylesheet will automatically format the resume cleanly into an A4/Letter document.
